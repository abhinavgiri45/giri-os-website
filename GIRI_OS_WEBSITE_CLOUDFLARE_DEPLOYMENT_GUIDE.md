# GIRI OS OFFICIAL WEBSITE — CLOUDFLARE PAGES DEPLOYMENT GUIDE

**Target Platform:** Cloudflare Pages (Direct Git Integration)  
**Repository:** [`abhinavgiri45/giri-os-website`](https://github.com/abhinavgiri45/giri-os-website)  
**Build Toolchain:** Vite 5 + TypeScript + React 18  
**Output Directory:** `dist`  
**Cost Tier:** 100% Free Tier Compatible (Zero Paid Services Required)

## 1. Prerequisites for Repository Owner

1. Access to the [Cloudflare Dashboard](https://dash.cloudflare.com/).
2. GitHub account (`abhinavgiri45`) connected to Cloudflare.
3. Code pushed to `abhinavgiri45/giri-os-website` on the `main` branch.

---

## 2. Step-by-Step Cloudflare Pages Setup

### Step 1: Create New Pages Project
1. Log in to the **Cloudflare Dashboard**.
2. In the left navigation menu, navigate to **Compute (Workers) > Workers & Pages**.
3. Click the **Create** button, then select the **Pages** tab.
4. Click **Connect to Git**.

### Step 2: Select GitHub Repository
1. Select your GitHub account: `abhinavgiri45`.
2. Locate and select the repository: **`giri-os-website`**.
3. Click **Begin setup**.

### Step 3: Configure Build & Deployment Settings
Fill out the configuration fields exactly as specified below:

| Field | Configuration Value | Explanation |
| :--- | :--- | :--- |
| **Project Name** | `giri-os-website` (or `girios`) | Defines your default `*.pages.dev` subdomain. |
| **Production Branch** | `main` | Production deployments trigger automatically on pushes to `main`. |
| **Framework Preset** | `Vite` | Pre-populates recommended defaults. |
| **Build Command** | `npm run build` | Compiles TypeScript and runs Vite production bundler. |
| **Build Output Directory** | `dist` | The compiled static assets directory generated by Vite. |
| **Root Directory** | `/` (Leave Blank or `/`) | Source code resides at the root of the repository. |

### Step 4: Environment Variables (Recommended)
Under **Environment Variables (Advanced)**, add:

| Variable Name | Value | Purpose |
| :--- | :--- | :--- |
| `NODE_VERSION` | `20` (or `22`) | Ensures Cloudflare build container runs modern Node.js runtime. |

### Step 5: Save and Deploy
Click **Save and Deploy**. Cloudflare Pages will clone the repository, execute `npm run build`, and deploy the contents of `./dist` across Cloudflare’s global edge network.

## 3. Client-Side SPA Routing & Security Validation

The repository includes pre-configured manifests in `./public/` that Cloudflare Pages automatically detects and enforces:

1. **`_redirects` (Single-Page Application Fallback):**
   ```text
   /*    /index.html   200
   ```
   Ensures that deep paths (e.g., `https://girios.org/features`, `/docs#virtualbox`, `/roadmap`) resolve directly to `index.html` without triggering HTTP 404 errors.

2. **`_headers` (Security & Immutable Caching):**
   ```http
   /*
     X-Frame-Options: DENY
     X-Content-Type-Options: nosniff
     Referrer-Policy: strict-origin-when-cross-origin
     Permissions-Policy: accelerometer=(), camera=(), geolocation=(), gyroscope=(), magnetometer=(), microphone=(), payment=(), usb=()
     Content-Security-Policy: default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline' https://fonts.googleapis.com; font-src 'self' https://fonts.gstatic.com; img-src 'self' data: https:; connect-src 'self'; frame-ancestors 'none';

   /assets/*
     Cache-Control: public, max-age=31536000, immutable
   ```

## 4. Custom Domain Configuration (Optional)

When the official domain (e.g. `girios.org`) is ready:
1. In the Cloudflare Pages project view, click the **Custom domains** tab.
2. Click **Set up a custom domain**.
3. Enter your domain (e.g. `girios.org` and `www.girios.org`).
4. If your DNS is managed on Cloudflare, DNS records and universal SSL certificates will be provisioned automatically.

## 5. Preview Deployments for Pull Requests

Cloudflare Pages automatically provisions isolated preview URLs for every pull request opened against `main`. This allows testing changes in a live edge staging environment before merging into production.
